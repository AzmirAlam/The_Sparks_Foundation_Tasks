# Task 1: Student Score Prediction

This task uses simple linear regression to predict a student's examination score from the number of hours studied.

## Workflow

- Import and inspect the dataset
- Explore correlation between hours and scores
- Split observations into training and testing sets
- Train and evaluate a linear regression model
- Compare predicted and actual results
- Predict the score for 9.25 study hours

## Files

- [`student-score-prediction.Rmd`](./student-score-prediction.Rmd) — analysis and model
- [`data/student_scores.csv`](./data/student_scores.csv) — source dataset
