# Task 3: Retail Data Analysis

This task will explore the Sample Superstore dataset to identify sales, profitability and customer-segment patterns.

## Planned workflow

- Clean and validate the dataset
- Examine sales and profitability
- Compare regions, categories and subcategories
- Investigate customer segments
- Identify loss-making products and markets
- Present business recommendations
